# 回声洞 · Echo Cave

SevenEndpoint Security Console「关于」页里那个抽奖洞的数据仓库：**每次点击随机抽出一条群友吹水发言，打字机效果逐字显示。**

## 数据结构

本仓库唯一的真源是 [`cave.json`](cave.json)：

```json
{
  "texts": [
    "一条发言",
    "另一条发言"
  ]
}
```

- `main` 分支上的 `cave.json` = **已审核通过**的文本，客户端启动抽奖时实时拉取。
- 客户端内置了一份种子文本，断网或本仓库不可达时兜底，功能永远可用。

## 投稿（所有人）

两种方式，任选其一：

### 方式 A：Pull Request（推荐）

1. Fork 本仓库
2. 编辑 `cave.json`，往 `texts` 数组里追加你的发言（**一行一条，带逗号，注意 JSON 语法**）
3. 提交 Pull Request

### 方式 B：Issue

开一个标题为 `投稿` 的 Issue，正文直接写文本，一行一条。由仓库所有者代为合并进 `cave.json`。

## 审核（仓库所有者）

- PR / Issue 即审核队列：**合并 = 过审上线**，关闭 = 拒稿
- 过审标准：不违法、不涉政、不人身攻击、不是广告
- 合并后无需发版，客户端下次抽奖自动读到新文本

## 许可

文本内容按原样提供，仅用于娱乐。
